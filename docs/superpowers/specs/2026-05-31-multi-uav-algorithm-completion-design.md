## GA_EQTSP 双地图扩展

### 当前实现分析

现有 `GA_EQTSP.py` 的核心逻辑：
- `comput_thought()`：沿直线采样，查询 A2G 地图获取数据速率，累加得到吞吐量矩阵
- `compute_weight_mec()`：计算权重矩阵 `weight = Data_size / throughput`
- `compute_dis_mat()`：最终距离矩阵 `dis = Euclidean × weight`

### 扩展方案

**代码实现（方案C：分阶段优化）**：

第一阶段：G2A 地图筛选
- 对每对巡检点 (i, j)，沿路径采样查询 G2A 地图
- 计算路径平均中断概率 `P_out_avg[i][j]`
- 标记高中断路径（`P_out_avg > threshold`）

第二阶段：A2G 地图优化
- 在可接受的路径中，使用 A2G 吞吐量计算权重
- 距离矩阵：`dis[i][j] = Euclidean(i,j) × (Data_size / throughput[i][j])`
- 对高中断路径施加大惩罚：`dis[i][j] += Ψ`（Ψ = 10^6）

**论文描述（方案A：乘法+硬惩罚）**：
```
D[i][j] = d_{i,j} × w_a2g[i][j] + w_g2a[i][j]
```
其中：
- `w_a2g[i][j] = I / Throughput[i][j]`（A2G 传输时间权重）
- `w_g2a[i][j] = Ψ × max(0, P_out[i][j] - P_out_max)`（G2A 安全惩罚）

## MA-TD3 通信奖励

### 当前奖励函数分析

现有 `MultiUAVWorld.py` 的 `_compute_rewards()` 包含：
- 进度奖励（progress）
- 势能奖励（potential）
- 对齐奖励（align）
- 到达奖励（reach）
- 碰撞惩罚（collision）
- 团队奖励（team）
- 时间惩罚（time）

### 新增通信奖励

**G2A 中断惩罚**：
```python
r_g2a = -alpha * P_out(current_position)
```
- P_out：当前位置的 G2A 中断概率（从 G2A 电磁地图查询）
- alpha：惩罚权重（建议 0.1 ~ 1.0）
- 物理含义：惩罚无人机进入通信盲区

**A2G 速率奖励**：
```python
r_a2g = beta * R_a2g(current_position) / R_max
```
- R_a2g：当前位置的 A2G 数据速率（从 A2G 电磁地图查询）
- R_max：最大数据速率（用于归一化）
- beta：奖励权重（建议 0.1 ~ 1.0）
- 物理含义：奖励无人机靠近高质量通信区域

**总通信奖励**：
```python
r_comm = r_g2a + r_a2g
```
